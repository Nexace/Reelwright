# Parity: hyperframes

Seeded 2026-11-06 from [the audit](../plans/phase-10-research/hyperframes.md) (Reelwright 0.2 status). A checkpoint that lands a feature flips its row's status here (EQUAL / BETTER, with the file that proves it); 10z compiles docs/PARITY.md from these files.

10a (2026-11-08): vendored HyperFrames updated 0.8.217 → 0.9.19; rows A4, A7–A9, A11–A14, C1, I1, I2, I7 flipped (I4, I6 updated).

## Legend

- **EQUAL** Reelwright does it as well; **BETTER** Reelwright does it better; **PARTIAL** some of it; **MISSING** not there.
- "(eng)" = the code is already in the vendored 0.8.217 engine/core/producer, so the feature is reachable from an `hf/` composition, but Reelwright's CLI, docs or authoring model do not expose it. It still counts as MISSING/PARTIAL for the user.
- OUT = excluded by owner decision (cloud render, HeyGen accounts/paid services) or repo rule (no MCP/plugin). Not counted in the four statuses.
- Licence column: licence of whatever must be vendored. Upstream repo is Apache-2.0 (no NOTICE file). Effort S = under a day, M = a few days, L = a week or more.
