# Phase 3 spec: look and feel

Branch `phase-3-design`. Status: spec approved 2026-10-31. 3a themes approved; 3b built. Local exit test passed; CI pending.

## 3a. Tokens, brand, themes, fonts

**Tokens.** `tools/kit.css` gets a `:root` block of `--kit-*` variables: `bg`, `ink`, `muted`, `accent`, `surface`,
`font-display`, `font-text`, `font-mono`, `radius`, `shadow`, `space`, plus caption tokens (`sub-bg`, `sub-ink`,
`sub-said`, `sub-font`, `sub-radius`). Every existing kit rule reads them, with defaults equal to today's values, so
films with no `style` render byte-identical to now (checked on `example` and `example-hf`).

**Themes.** `themes/<name>.css`: token values, including motion (`--kit-ease`, `--kit-tempo`) and caption style, so
one file per theme (built: no `theme.json`; `@font-face` rules are generated by `tools/theme.mjs` from the font tokens). Picked by `"style": "<name>"` in
`project.json`, or `--style <name>` on the command line (output `out/<name>-<style>.mp4`). `tools/theme.mjs` (called by `render.mjs`) writes
`theme.css` beside the film's `index.html`, which links it after kit.css; `engine.js` reads the tokens, loads every declared font before `READY`, and exposes
`KIT.theme`, `KIT.ease` and `KIT.dur(s)` so motion follows the theme. The HF renderer copies the theme and its fonts
into `hf/kit/` (HyperFrames only serves the composition folder).

Ten themes, each a display + text pairing (all SIL OFL, from Google Fonts):

| Theme | Look | Fonts |
|---|---|---|
| editorial | cream paper, black ink, red accent, calm easing | Playfair Display + Source Serif 4 |
| brutalist | white, black borders, hard offset shadows, yellow, no radius, snappy | Archivo Black + Space Mono |
| pastel | lavender/peach, big radius, soft shadows, gentle | Quicksand + Nunito |
| dark-tech | near-black, mint accent, mono labels (closest to today's example-hf) | Space Grotesk + JetBrains Mono |
| playful | bright primaries, bouncy outBack | Fredoka + Nunito |
| retro | 70s orange/brown/cream, chunky display | Shrikhand + Work Sans |
| swiss | white grid, red accent, tight grotesk | Inter Tight + Inter |
| luxury | black and gold, thin serif, slow | Cormorant Garamond + Montserrat |
| clean | white/blue SaaS look | Manrope |
| neon | deep purple, magenta/cyan glow | Syne + Space Grotesk |

**Brand.** Optional `projects/<name>/brand.json`: `colors` (any token), `fonts` (`display`/`text`: a bundled family
or a local file in the project), `logo` (path, exposed as `KIT.brand.logo` and `--kit-logo`), `tone` (free text,
for the writer; no effect on render). Applied after the theme, so a brand wins.

**Fonts.** `fonts/<family>/` holds latin-subset `.woff2` files (only the weights themes use) and the family's
`OFL.txt`; `fonts/LICENSES.md` lists family, version, source URL, license. Fetched by `node fonts/fetch.mjs` (17 families, 736 KB), committed. Bundled fonts make macOS and Windows render the same.

**Checkpoint:** a contact sheet of `example-hf` in all ten themes for your approval before 3b.

## 3b. Layouts and formats

**Layouts.** `tools/layouts.js` (loaded by `engine.js` for both renderers): `KIT.layout.split`, `fullBleed`,
`bento`, `tiltedDevice`, `stat`, `quote`, `kinetic`. Each builds its DOM once and returns `{ el, set(t, p) }`,
styled in `kit.css` from tokens only, sized from `KIT.safe` so it works in every format. PLAYBOOK.md gets a section
on when to use each.

**Formats.** `--formats 16x9,9x16,1x1` (1920×1080, 1080×1920, 1080×1080) on `film`/`all`/`stills`. Audio is built
once; each format renders to `frames-<fmt>/` and `out/<name>-<fmt>.mp4`. `KIT.fmt` and `KIT.safe` (`{x, y, w, h}`
inside title-safe margins, plus a `--kit-u` CSS unit that scales with the short side) let one `film.js` adapt.
To check: HyperFrames reads `data-width`/`data-height` from the composition root; the renderer will rewrite them per
format in a temp copy of `hf/` if setting them at load isn't enough.

## Changes to existing films

`example-hf/film.js` is edited once to use tokens, `KIT.ease`/`KIT.dur` and `KIT.safe`, and gets `"style": "dark-tech"`.
After that, switching theme or format needs no edit. pvk films and their frames stay unchanged.
