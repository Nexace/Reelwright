# PLAYBOOK topics (stitched into docs/PLAYBOOK.md as of 0.3)

As of release 0.3 every topic in this folder is stitched into [docs/PLAYBOOK.md](../PLAYBOOK.md), which is the
document to read. These files stay as the sources: a new topic is still written here first, as
`docs/playbook/<topic>.md` (one file per topic, so parallel work never edits the same lines), and then stitched into
docs/PLAYBOOK.md under a `## Title (code refs)` heading. If you change a fact in a topic file, change it in the
PLAYBOOK section too.
