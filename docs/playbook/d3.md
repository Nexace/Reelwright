# d3 in a film (scales, shapes, delaunay)

d3 7.9.2 (UMD, includes d3-delaunay) is vendored in `vendor/d3/`. In a HyperFrames film it is copied to `hf/kit/d3/d3.min.js`; in a pvk film load `../../../vendor/d3/d3.min.js` with a script tag. The map blocks already use it.

The rule: d3 gives pure functions, `render(t)` calls them. Everything is computed from `t`; nothing runs on a clock.

| Use | Do not use |
|---|---|
| `scaleLinear`, `scaleBand`, `scaleSequential` with `interpolateViridis` and the other interpolators, `scaleTime` | `d3.transition()`, `selection.transition()` |
| `line`, `area`, `arc`, `pie`, `stack`, `geoPath` and projections | `d3.timer`, `d3.interval`, `d3.now` |
| `Delaunay.from(points)`, `.voronoi(box)`, `.find(x, y)` | `d3.drag`, `d3.zoom` (events, not time) |
| `interpolate`, `interpolateString`, `interpolateRound` | force simulations run live: precompute `simulation.tick(300)` once at load |

Queued work is the same problem as a transition: `tools/checks/d3-clock.py` warns in `qa` when film code uses a d3 clock. An in-render `Math.random()` is the other trap: use a seeded function.

```js
// svg#s, 320x180: a delaunay mesh of 24 fixed points whose colour sweeps with t, and a line that draws on
const svg = d3.select('#s'), W = 320, H = 180, N = 24;
const pts = Array.from({ length: N }, (_, i) => [((i * 97) % 280) + 20, ((i * 53) % 140) + 20]);   // fixed, no random
const mesh = d3.Delaunay.from(pts), vor = mesh.voronoi([0, 0, W, H]);
const cells = pts.map((_, i) => svg.append('path').attr('d', vor.renderCell(i)).attr('stroke', '#fff'));
const color = d3.scaleSequential(d3.interpolateViridis).domain([0, 1]);
const x = d3.scaleLinear().domain([0, 4]).range([10, W - 10]), y = d3.scaleLinear().domain([-1, 1]).range([H - 10, 10]);
const path = svg.append('path').attr('fill', 'none').attr('stroke', '#fff').attr('stroke-width', 3);
const xs = d3.range(0, 4.001, 0.05), line = d3.line().x((d) => x(d)).y((d) => y(Math.sin(d * 3)));
function render(t) {
  cells.forEach((c, i) => c.attr('fill', color(((i / N) + t * 0.25) % 1)));
  path.attr('d', line(xs.filter((d) => d <= Math.min(4, t * 1.5))));
}
```

## In a film

- Time the sweep and the draw-on with `V()`, `W()` and `KIT.snap()`: the example above uses `t` for brevity.
- Clip the drawing to the safe box (`KIT.safe`) and size text in `--kit-u`.
- The test that runs this snippet under shuffled seeks is `tools/selfcheck/p8-d3.mjs`.
